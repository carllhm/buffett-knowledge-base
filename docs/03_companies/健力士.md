# 健力士 Guinness plc

## 公司简介

健力士（Guinness plc）是英国历史悠久的啤酒酿造集团，以烈性黑啤酒闻名于世，业务遍及全球。1980年代中期，公司陷入一桩涉及非法酒精定价和利润操纵的丑闻（"健力士事件"），导致高管层动荡和声誉危机。巴菲特曾在此时期认真评估收购健力士的可行性。

## 投资时间线

- **1980年代中期**：健力士丑闻期间，巴菲特认真研究收购可能性
- **评估后放弃**：经过深入分析，巴菲特最终决定不进行收购
- **后续发展**：健力士通过重组走出丑闻，逐步转型为全球性饮料集团

## 巴菲特评价

巴菲特在1989年致股东信中披露了他对健力士的思考过程。当时健力士因丑闻而股价低迷，巴菲特和芒格认为这家公司的品牌价值——尤其是健力士这个全球知名的爱尔兰黑啤品牌——被市场低估了。

然而，经过进一步分析，巴菲特意识到几个关键障碍：海外收购的复杂性、对英国法律和监管环境的不熟悉、以及丑闻可能带来的潜在法律风险。最终，他选择遵守"能力圈"原则——不投资自己无法充分评估风险边界的公司。巴菲特强调，宁可错过一个看似诱人的机会，也不应在不了解的领域冒无法量化的风险。

## 关键语录

> "我们曾经认真考虑过收购健力士。这是一家拥有强大品牌的企业，但我们对英国法律体系不够了解，对丑闻可能延伸的法律后果也无法准确评估。最终我们决定——宁可错过，也不冒险踏入能力圈之外的领域。"
