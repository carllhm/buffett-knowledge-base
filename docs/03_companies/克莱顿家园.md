# 克莱顿家园（Clayton Homes）

## 基本信息

| 属性 | 内容 |
|------|------|
| 英文名 | Clayton Homes |
| 行业 | 预制房屋建造与融资 |
| 总部 | 田纳西州诺克斯维尔 |
| 伯克希尔持股 | 100%（2003年收购） |
| 收购价格 | 约17亿美元 |
| 创始人 | 吉姆·克莱顿（1956年创办） |
| 现任CEO | 凯文·克莱顿 |

## 核心业务

克莱顿家园是美国最大的预制房屋（manufactured home）建造商：
- 年产超过4万套房屋
- 提供房屋建造和融资一体化服务
- 通过旗下Vanderbilt Mortgage提供贷款
- 雇佣约14,000名员工

## 收购故事

### 背景
- **2003年8月**：伯克希尔以约17亿美元收购100%股权
- 收购机会由田纳西大学学生推荐
- 巴菲特看中了预制住房市场的长期潜力

### 投资逻辑
1. **可负担住房需求**：美国约22%的住房是预制房屋
2. **垂直整合模式**：建造+融资一体化
3. **管理团队**：吉姆·克莱顿和凯文·克莱顿家族经营

## 业务模式

### 预制房屋优势
- 建造成本低于传统房屋30-40%
- 交付时间短
- 质量控制好
- 适合首次购房者和老年downsizers

### 融资业务
- Vanderbilt Mortgage提供分期贷款
- 通常是15-30年固定利率贷款
- 违约率相对较高，但利差可观
