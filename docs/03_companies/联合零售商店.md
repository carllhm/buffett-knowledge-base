# 联合零售商店（Associated Retail Stores）

## 基本信息

| 属性 | 内容 |
|------|------|
| 英文名 | Associated Retail Stores / Diversified Retailing Company |
| 行业 | 百货零售 |
| CEO | 本·罗斯纳（Ben Rosner） |
| 收购主体 | 多元零售公司（Diversified Retailing Company） |
| 收购时间 | 1966-1967年 |
| 伯克希尔持股 | 通过多元零售公司收购，后并入伯克希尔 |

## 核心业务

百货零售连锁经营，在本·罗斯纳的经营管理下成为行业标杆型企业。

## 收购故事

### 收购背景
- **1966-1967年**：巴菲特通过多元零售公司（Diversified Retailing Company）收购联合零售商店
- 多元零售公司是巴菲特早期收购的重要载体，后成为伯克希尔帝国的重要基石
- 收购完成后，多元零售公司与伯克希尔哈撒韦合并

### 收购逻辑
1. **管理型人才**：本·罗斯纳是巴菲特极度欣赏的管理者典范
2. **成本控制**：罗斯纳将成本控制做到极致，是零售业的标杆
3. **业务协同**：与[[蓝筹印花]]等业务形成协同效应
4. **长期价值**：管理层优秀，能持续创造超额价值

## 核心管理层

### 关键人物

| 姓名 | 职位 | 特点 |
|------|------|------|
| 本·罗斯纳（Ben Rosner） | CEO | 成本控制大师，零售业管理典范 |

### 管理特点
- **极致成本控制**：罗斯纳以严苛的成本管理著称，是巴菲特心中理想管理者的代表
- **高效运营**：在零售行业微薄的利润率中创造超额回报
- **长期任职**：长期服务于公司，与巴菲特保持良好信任关系

## 巴菲特评价摘录

> "本·罗斯纳是零售业最优秀的管理者之一，他将成本控制做到了极致。" —— 巴菲特

> "我们寻找的不是会花公司钱的管理者，而是会替股东省钱的管理者。罗斯纳就是典范。" —— 巴菲特

## 在伯克希尔体系中的位置

### 多元化零售公司时期
- 巴菲特通过[[蓝筹印花]]控股多元零售公司
- 联合零售商店是多元零售公司的核心资产
- 罗斯纳作为核心管理者，负责日常运营

### 与伯克希尔合并
- 多元零售公司后来与[[伯克希尔哈撒韦]]合并
- 联合零售商店成为伯克希尔零售版图的重要组成部分
- 巴菲特通过这一模式实现了"保险+零售"的双轮驱动
