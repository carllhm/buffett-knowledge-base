# 内布拉斯加家具城（Nebraska Furniture Mart）

## 基本信息

| 属性 | 内容 |
|------|------|
| 英文名 | Nebraska Furniture Mart (NFM) |
| 行业 | 家具/家居零售 |
| 成立年份 | 1937年 |
| 总部 | 内布拉斯加州奥马哈 |
| 伯克希尔持股 | 90%（1983年收购） |
| 收购价格 | 约5,500万美元（多数股权） |

## 核心业务

美国最大的单店家居零售商，主营家具、地毯、电器等。单店年销售额超1亿美元，超过奥马哈所有竞争对手总和。

## 收购故事

### 背景
- B夫人（Rose Blumkin）1937年用500美元创办
- 1983年单店年销售额已超1亿美元
- 巴菲特长期观察，了解其竞争力

### 收购条款
- 1983年收购90%股权
- B夫人家族保留10%
- 关键年轻经理获得10%期权激励
- **无审计、无库存盘点、无资产核实**

### 收购原因
1. **极致低成本运营**：毛利率仅20%+，运营费用率16.5%
2. **采购优势**：Louie Blumkin是全美最精明采购员
3. **管理传奇**：B夫人90岁仍一周七天在卖场
4. **本地垄断**：远超所有竞争对手效率

## 核心竞争优势

### 1. 成本优势
- 运营费用率仅16.5%（行业标杆Levitz为35.6%）
- 极低毛利率但有盈利能力
- 采购规模议价权强

### 2. 管理效率
- 无复杂管理系统
- 家族式经营，决策快速
- 员工忠诚度高

### 3. 品牌效应
- 奥马哈本地绝对领先
- 口碑传播，获客成本低

## 管理团队

### 关键人物

| 姓名 | 职位 | 贡献 |
|------|------|------|
| [B夫人（Rose Blumkin）](../04_人物库/B夫人.md) | 创始人/董事长 | 1937年创立，90+岁仍在工作 |
| [Louie Blumkin](../04_人物库/Louie_Blumkin.md) | 总裁 | 全美最精明采购员 |
| Ron、Irv、Steve Blumkin | 管理层 | 第三代家族成员 |

### B夫人传奇
- **1893年**：生于俄国，未受过正规教育
- **1937年**：500美元创办家具店
- **1983年**：90岁，一周七天在卖场卖地毯
- **1984年**：91岁仍每周工作七天
- **1987年**：94岁仍在工作
- **格言**："低价卖，说实话"

## 后续发展（1990年代至今）

### 家族传承
- **1998年**：B夫人94岁去世，传奇落幕
- Ron、Irv、Steve Blumkin第三代继续经营
- 2000年代持续保持盈利

### 扩张计划
- **2015年**：首家分店落户堪萨斯州雷内克萨
- **2017年**：爱荷华州分店开业
- **2021年**：密苏里州分店开业
- 保持单店效率的同时稳健扩张

### 火灾事件
- 2019年奥马哈旗舰店发生火灾
- 迅速重建，继续运营
