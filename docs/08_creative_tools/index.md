# 创作工具箱

为视频号和公众号创作者提供的实用指南。

## 选题工具

### 从股东信中挖掘选题的路径

**投资案例拆解**：每年股东信都有大量真实投资案例（桑博恩地图、登普斯特、GEICO等），每个案例都是独立的深度选题。拆解路径：背景→买入逻辑→持有过程→结果→启示。

**概念澄清型**：针对常见投资误解撰写澄清文章（如"巴菲特为什么不买黄金""为什么复利这么重要"），以股东信原文为依据。

**历史对比型**：将巴菲特在不同历史时期对同一问题的态度变化做纵向对比（如1990年代vs2008年对银行的态度）。

**金句视频型**：选一句有视觉冲击力的话，配上巴菲特演讲画面或静态图片，制作15-60秒短视频。

### 推荐选题方向

| 方向 | 示例标题 | 适合时长 |
|------|---------|---------|
| 案例深度拆解 | 《1967年巴菲特花5400万买的是什么》 | 3-8分钟 |
| 概念通俗解读 | 《什么是浮存金，巴菲特怎么用它赚钱》 | 2-5分钟 |
| 人物故事 | 《让巴菲特佩服的人是怎么做生意的》 | 3-5分钟 |
| 数据可视化 | 《巴菲特60年收益率可视化》 | 1-3分钟 |
| 年度总结 | 《2024年巴菲特最新说了什么》 | 5-10分钟 |

## 数据查询

### 伯克希尔·哈撒韦

- **股价历史**：Yahoo Finance (BRK.A / BRK.B)、macrotrends.net
- **SEC filings**：sec.gov/cgi-bin/browse-edgar?action=getcompany&CIK=BRK
- **年报原文**：berkshirehathaway.com/releases.html

### 历史收益率

- 历年道指表现：investopedia.com
- 巴菲特合伙企业收益率（1957-1969）：见本知识库各年核心总结页
- 伯克希尔股价/净值历史：macrotrends.net/stocks/compare

### 持仓变化

- 13F filings (SEC EDGAR)：季度更新，可追踪巴菲特调仓
- 伯克希尔年报：每年2月发布，含完整持仓明细

## 图片素材

### 合法获取渠道

| 资源 | 来源 | 备注 |
|------|------|------|
| 巴菲特照片 | Wikimedia Commons（部分免费） | 需确认版权 |
| 伯克希尔年会 | CNP Archives | 部分公开 |
| 奥马哈总部 | Berkshire Hathaway官网媒体资料 | 需申请 |
| 人物照片 | 各公司官网/新闻稿 | 通常可转载 |

### 工具推荐

- **Canva** / **Figma**：快速制作图文封面
- **Pexels / Unsplash**：无版权股票/金融背景图
- **DALL-E / Midjourney**：生成巴菲特风格插画（避免真实人脸）

### 注意事项

- 避免使用未授权的年会现场视频截图
- 巴菲特个人肖像权：公开演讲画面通常可合理使用
- 品牌Logo使用：伯克希尔/可口可乐等公司Logo用于事实陈述场景通常属合理使用


## 合规提醒

### 版权说明

- 巴菲特致股东信原文：伯克希尔官方发布，属公开信息，可引用
- 引用建议：单次引用不超过300字，并注明来源
- 翻译稿：需注明"译文来自网络/译者"，本知识库翻译仅供参考

### 原创声明建议

发布内容时注明：
> 本文部分内容参考伯克希尔·哈撒韦年报（berkshirehathaway.com），数据截止[年份]。

### 避免事项

- 不要将翻译稿声称是自己的原创翻译（可说明"参考网络译本整理"）
- 不要引用未确认来源的具体数据（建议交叉验证）
- 投资建议类内容需注意合规表述（避免"买入/卖出"建议）
