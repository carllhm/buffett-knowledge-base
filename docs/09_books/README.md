# 经典著作

本模块收录巴菲特投资思想的经典来源著作，结合巴菲特70年致股东信原文进行交叉解读。

## 📖 当前著作

### 巴菲特之道（The Warren Buffett Way）

**作者：** Robert G. Hagstrom  
**出版：** 第3版（2014年）  
**核心框架：** 4大类12条投资准则

| 类别 | 准则 |
|------|------|
| 🏢 企业准则 | 企业规模、主营业务、长期竞争力 |
| 👔 管理准则 | 理性、坦诚、独立思考 |
| 💰 财务准则 | 净资产收益率、利润率、1美元原则 |
| 📈 市场准则 | 价值区间、安全边际 |

> 本书系统总结了巴菲特如何从格雷厄姆的"烟蒂投资法"转型为"优质企业投资法"的关键思想演变，结合伯克希尔35年的投资实践案例。
