# 巴菲特之道

> **作者：** Robert G. Hagstrom | **翻译：** 杨天南 | **版本：** 第3版 | **出版：** 2015

## 书籍简介

《巴菲特之道》是第一本将巴菲特思想引进中国的书，自1994年出版以来，已畅销120万册。本书系统性地总结了巴菲特投资方法的四大类12条准则。

> **"本书揭示出，巴菲特的成就就是非凡的，巴菲特的投资方法也是非凡的，但他的方法却是可以为普通投资者所学习和应用的。"** —— 《华尔街日报》
