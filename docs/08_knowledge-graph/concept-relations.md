## 学习路径建议

**入门路径：** 内在价值 → 护城河 → 安全边际 → 能力圈

**进阶路径：** 保险浮存金 → 承保纪律 → 资本配置 → 透视盈利

**高阶路径：** 管理层选择 → 公司治理 → 声誉 → 错误坦诚

**实战路径：** 逆向思维 → 风险 → 长期主义 → 复利
