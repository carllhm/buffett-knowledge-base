# 杰克·林格沃尔特（Jack Ringwalt）

- **角色职位**：国民赔偿公司创始人
- **与巴菲特关系**：国民赔偿保险公司的创始人，后成为伯克希尔保险体系的重要成员

## 主要事迹

杰克·林格沃尔特是国民赔偿保险公司（National Indemnity Company）的创始人，这家公司在巴菲特的保险帝国中占据着举足轻重的地位。国民赔偿公司最初由林格沃尔特创办，早期只是一家小型再保险公司，专门承保大型商业风险。在他的经营下，公司积累了独特的核保专业能力和审慎的风险管理文化，这在后来对巴菲特极具吸引力。

巴菲特对保险业务有着深刻的理解和长期的热情，他深知保险浮存金对于投资业务的重要价值。当机会出现时，巴菲特收购了国民赔偿公司，将其纳入伯克希尔的保险版图。林格沃尔特创办的这家公司以其严格的核保纪律著称，宁可放弃业务也不愿以过低价格承保风险，这一理念与巴菲特的投资哲学高度契合。

国民赔偿公司在加入伯克希尔后继续发挥重要作用，其稳定的承保利润和充裕的浮存金成为巴菲特进行权益类投资的重要资金来源。林格沃尔特所奠定的高标准核保文化和审慎经营原则被长期保留下来，成为伯克希尔保险业务的重要组成部分。他所创立的公司至今仍是伯克希尔保险帝国中历史最悠久、最受信赖的品牌之一。

## 关键年份事件

- **创办期**：创立国民赔偿公司，建立审慎承保的经营原则
- **1967年**：巴菲特收购国民赔偿公司，公司成为伯克希尔保险体系核心
- **1970年代至今**：公司持续为伯克希尔提供浮存金支持
