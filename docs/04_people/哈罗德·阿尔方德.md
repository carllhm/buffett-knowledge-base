# 哈罗德·阿尔方德（Harold Almand）

- **角色职位**：德克斯特鞋业创始人
- **与巴菲特关系**：被伯克希尔收购的制鞋公司创始人

## 主要事迹

哈罗德·阿尔方德是德克斯特鞋业（Dexter Shoe Company）的创始人。德克斯特鞋业是美国知名的制鞋企业，主营业务涵盖男鞋、女鞋和童鞋的生产与销售，在美国本土市场拥有广泛的零售网络和忠实的消费者基础。公司以可靠的产品质量和舒适的设计著称，在竞争激烈的美国鞋类市场中占据了稳定的市场份额。

巴菲特对德克斯特鞋业的收购是其制鞋行业投资策略中的重要一环。在完成收购后，德克斯特鞋业成为伯克希尔·哈撒韦旗下重要的制鞋业务板块。巴菲特对阿尔方德创办的这家公司青睐有加，高度评价其品牌价值和市场竞争地位。德克斯特鞋业在被收购后继续以独立品牌运营，在伯克希尔的财务支持下保持稳定的业务增长。

阿尔方德作为公司的创始人，在企业文化的塑造和经营原则的确立方面留下了深刻印记。他所建立的注重品质和客户服务的经营哲学，在公司被伯克希尔收购后得以延续。德克斯特鞋业后来与 H.H. Brown 等伯克希尔旗下其他制鞋业务形成了协同效应，共同构成伯克希尔制造业板块的重要组成部分。

## 关键年份事件

- **创办期**：创立德克斯特鞋业，建立品牌在美国鞋类市场的地位
- **收购**：公司被伯克希尔·哈撒韦收购，成为伯克希尔制鞋板块成员
- **收购后**：德克斯特品牌保持独立运营，继续在美国鞋类市场发展
