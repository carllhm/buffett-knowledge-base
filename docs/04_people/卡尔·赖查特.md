# 卡尔·赖查特

- **角色职位**：富国银行（Wells Fargo）CEO
- **与巴菲特关系**：1990年前担任富国银行CEO，带领银行走出困境，是巴菲特最重要的银行投资对象之一

## 主要事迹

卡尔·赖查特是富国银行历史上最具传奇色彩的CEO之一。在1980年代末至1990年代初美国银行业最困难的时期，赖查特临危受命，将富国银行从困境中拉回正轨。1989年他出任CEO时，银行正面临严重的房地产贷款坏账问题，整个银行业也因储贷危机而风声鹤唳。

赖查特以果断的决策和坚定的执行力著称。他迅速削减不良资产，重组银行管理结构，并在艰难的环境中保持了银行的资本充足。赖查特的领导力不仅帮助富国银行渡过了危机，更为其后来成为美国四大银行之一奠定了基础。

巴菲特正是在这一时期发现了富国银行的价值。尽管当时许多投资者对银行业避之不及，巴菲特却看到了富国银行的内在潜力，并开始大举建仓。他高度评价赖查特的管理能力，认为赖查特是在正确的时间出现的正确人选。巴菲特后来多次表示，富国银行是其最成功的投资之一，而这在很大程度上要归功于赖查特打下的坚实基础。

## 关键年份事件

- **1989年**：出任富国银行CEO，着手处理不良贷款问题
- **1990年**：在银行业危机中成功稳定富国银行财务状况
- **1990年后**：继续领导富国银行，为其后来成长为美国顶级银行奠定基础
