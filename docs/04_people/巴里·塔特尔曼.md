# 巴里·塔特尔曼

- **角色职位**：乔丹家具（Jordan Furniture）创始人
- **与巴菲特关系**：将乔丹家具带入伯克希尔·哈撒韦收购视野的企业创始人

## 主要事迹

巴里·塔特尔曼是乔丹家具（Jordan Furniture）的创始人。乔丹家具是美国东北部地区知名的家具零售商，在新英格兰地区拥有多家门店，以其优质的服务和丰富的产品线著称。塔特尔曼作为创始人，从一家地方家具店起步，凭借对本地市场的深刻理解和真诚的经营理念，逐步将乔丹家具打造为区域市场的领先品牌。

乔丹家具的经营风格以顾客导向著称，塔特尔曼强调与顾客建立长期信任关系，而非追求短期交易最大化。这种价值观与巴菲特选股时看重"受尊敬的管理层和经久不衰的品牌声誉"高度一致。乔丹家具最终进入伯克希尔的收购视野，正是巴菲特在消费零售领域持续寻找优质标的的结果。

作为创始人，塔特尔曼在乔丹家具被收购后继续发挥重要作用，确保了公司文化的延续和员工队伍的稳定。伯克希尔收购后通常保留原有的管理团队，这一做法在乔丹家具案例中也得到了体现，使得公司在过渡期保持平稳运营，继续服务其在新英格兰地区的忠实顾客群体。

## 关键年份事件

- **创立期**：创立乔丹家具，逐步发展成新英格兰地区领先的家具零售商
- **被收购期**：乔丹家具被伯克希尔·哈撒韦收购，成为伯克希尔消费板块的一部分
- **持续经营期**：在伯克希尔控股下，乔丹家具保持品牌独立运营，服务区域市场顾客
