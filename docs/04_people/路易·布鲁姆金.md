# 路易·布鲁姆金

- **角色职位**：内布拉斯加家具城（NFM）管理者
- **与巴菲特关系**：B夫人（罗斯·布鲁姆金）之子，NFM家族传承的关键人物

## 主要事迹

路易·布鲁姆金是传奇零售巨头——内布拉斯加家具城（Nebraska Furniture Mart，简称NFM）创始人B夫人（罗斯·布鲁姆金）的儿子。在母亲的培养和引导下，路易·布鲁姆金逐步成长为NFM的核心管理者，延续了这一家族零售传奇。

路易从小在NFM的柜台边长大，亲眼见证了母亲白手起家的过程。NFM从一家小型家具店发展成为内布拉斯加州最大的家具零售商，并成为伯克希尔·哈撒韦旗下重要的零售业务板块。路易在母亲退休或过世后，承担起了延续NFM辉煌的使命。

路易·布鲁姆金忠诚地继承了母亲"薄利多销、童叟无欺"的经营理念，保持了NFM在奥马哈家具市场的绝对领先地位。他与巴菲特保持着良好的信任关系，延续了B夫人与巴菲特建立的合作传统，使NFM继续为伯克希尔贡献稳定且可观的利润。

## 关键年份事件

- **1980年代以前**：在NFM从基层做起，逐步学习零售业务
- **B夫人退休后**：接任NFM管理职务，确保公司平稳过渡
- **延续至今**：继续领导NFM，延续家族零售传奇
