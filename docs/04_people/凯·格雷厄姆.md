# 凯·格雷厄姆（Katharine Graham）

## 基本信息

| 属性 | 内容 |
|------|------|
| 全名 | Katharine Meyer Graham |
| 出生 | 1917年6月16日，纽约 |
| 逝世 | 2001年7月17日（84岁） |
| 职业 | 出版人、企业家 |
| 公司 | [[华盛顿邮报]] |

## 职业生涯

### 早年
- 1917年生于纽约，父亲尤金·梅耶（Eugene Meyer）是富有的银行家
- 毕业于瓦萨学院和芝加哥大学
- 1933年父亲买下《华盛顿邮报》
- 1940年嫁入格雷厄姆家族，丈夫菲利普·格雷厄姆（Philip Graham）接管邮报

### 从主妇到掌门人
- 长期在丈夫光环下，自信被严重压抑
- 1963年丈夫因抑郁症自杀，凯被迫接手
- 1969年将华盛顿邮报公司上市
- **1971年成为华盛顿邮报公司CEO——美国首位《财富》500强女CEO**
- 1972年推动《华盛顿邮报》上市，并掌管旗下四家电视台和《新闻周刊》

## 水门事件

### 历史性时刻
| 时间 | 事件 |
|------|------|
| 1972年6月 | 五人闯入水门大厦民主党总部 |
| 1972年 | 邮报记者鲍勃·伍德沃德和卡尔·伯恩斯坦持续追踪 |
| 1972-1974年 | 凯顶住白宫巨大压力，坚持发表调查报道 |
| 1974年8月 | 尼克松总统辞职 |

### 关键决策
- 白宫威胁取消邮报电视台执照、限制其上市
- 凯承受巨大心理压力（自称"每天早上都在想是否该退缩"）
- 依然坚持新闻独立原则，让记者放手报道
- **水门事件使《华盛顿邮报》成为美国新闻自由的象征**

### 名言

> "决定发表那些报道是我做过最孤独的决定。" —— 凯·格雷厄姆

## 与巴菲特的友谊

### 结识与投资
| 时间 | 事件 |
|------|------|
| 1973年 | 巴菲特以约1,060万美元买入华盛顿邮报公司约10%股份 |
| 1974年 | 巴菲特加入华盛顿邮报公司董事会 |
| 1974-2001年 | 巴菲特担任董事长达27年 |
| 1970s-2001年 | 凯与巴菲特建立深厚友谊，频繁请教商业决策 |

### 亦师亦友
- 凯缺乏商业背景，巴菲特成为她最重要的商业导师
- 巴菲特教会她理解市值、市盈率等基本商业概念
- 凯经常深夜打电话向巴菲特请教
- 巴菲特帮她抵御了收购威胁，保护了邮报的独立性
- 两人关系超越了商业伙伴，成为终身挚友

### 巴菲特的角色
- **商业顾问**：指导凯理解财务报表和公司治理
- **董事会成员**：27年任期中提供战略建议
- **保护者**：在敌意收购威胁时帮助凯设计防御方案
- **精神支持**：在凯最缺乏自信时给予鼓励

## 巴菲特评价

### 经典语录

> "凯是我见过的最杰出的CEO之一。在商业判断力方面，她比我所认识的大多数男性高管都更出色。" —— 巴菲特

> "她接手邮报时对自己毫无信心，但她有一种品质——她会倾听，会学习，然后做出正确决策。"

> "凯·格雷厄姆是我最敬佩的人之一。她从一个觉得自己什么都不知道的人，成长为美国最受尊敬的企业领袖。"

### 在股东信中的提及
- 多次称赞华盛顿邮报作为优秀企业的典范
- 将凯列为最欣赏的CEO之一
- 以邮报为例说明"经济护城河"的概念——报纸在特定城市拥有垄断地位

## 个人回忆录

- 1997年出版自传《**个人历史**》（Personal History）
- 荣获**1998年普利策传记奖**
- 坦诚记录了自己从缺乏自信到成为强势领导者的转变过程
- 成为无数女性的精神灯塔

## 影响

### 对新闻业
- 水门事件重塑了美国新闻业的标准
- 证明了独立调查报道可以改变国家历史
- 《华盛顿邮报》在她的领导下成为世界顶级报纸之一

### 对女性
- 作为首位《财富》500强女CEO，打破了企业界的性别天花板
- 证明了女性完全有能力领导大型企业
- 其自传激励了无数职业女性

### 对巴菲特投资理念
- 华盛顿邮报是巴菲特经典投资案例之一
- 1973年投资约1,060万美元，到2014年伯克希尔出售时价值超过**12亿美元**
- 完美诠释了"以合理价格买入伟大企业，长期持有"的理念
