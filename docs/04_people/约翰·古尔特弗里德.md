# 约翰·古尔特弗里德

- **角色职位**：所罗门兄弟（Salomon Inc.）CEO
- **与巴菲特关系**：1991年国债丑闻期间担任所罗门兄弟CEO，巴菲特临危受命介入救援

## 主要事迹

约翰·古尔特弗里德在1991年担任所罗门兄弟CEO期间，经历了这家公司历史上最严峻的危机——国债拍卖丑闻。1991年，所罗门兄弟因在国债拍卖中违规投标而遭受调查，公司一度濒临崩溃边缘。这起事件将所罗门兄弟和整个美国金融市场都推向了动荡之中。

就在危机最严重的时刻，沃伦·巴菲特以"紧急救火队员"的身份介入所罗门兄弟。巴菲特不仅是所罗门的大股东，更在危机关头亲自致电财政部保证公司信誉，并派驻芒格等人协助稳定局势。古尔特弗里德作为时任CEO，在这场危机中承受着巨大的压力。

巴菲特最终在1991年9月亲自担任所罗门临时董事长，直到公司度过最困难的时期。这段经历成为巴菲特商业生涯中少数几次直接介入日常管理的案例。虽然古尔特弗里德最终离任，但所罗门兄弟最终在巴菲特的主导下稳定下来，并在此后保持了相对稳健的发展。古尔特弗里德亲历的这场危机，也成为后来巴菲特在股东信中反复提及的风险管理案例。

## 关键年份事件

- **1991年**：担任所罗门兄弟CEO，遭遇国债拍卖违规丑闻
- **1991年**：丑闻曝光后辞任CEO，巴菲特介入担任临时董事长
- **1991年后**：离开所罗门，所罗门在巴菲特主导下度过危机
