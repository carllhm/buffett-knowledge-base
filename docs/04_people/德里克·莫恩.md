# 德里克·莫恩（Derek Mau）

- **角色职位**：所罗门兄弟投资银行负责人
- **与巴菲特关系**：巴菲特收购所罗门兄弟后的核心管理层成员

## 主要事迹

德里克·莫恩在所罗门兄弟公司担任投资银行部门负责人，是巴菲特接管所罗门后倚重的关键人物之一。1991年，所罗门兄弟因交易员约翰·梅里韦瑟违规炒作美国国债而陷入空前危机，公司面临被吊销国债交易资格的严峻局面，可能导致破产边缘。在此危急时刻，巴菲特以"救火队长"身份介入，莫恩成为协助稳定公司运营的核心高管之一。

巴菲特在深入调查后发现，所罗门的问题根源在于内部监管失效和风控体系存在严重漏洞，而并非整个公司管理层的问题。莫恩在此后的公司重建过程中发挥了重要作用，帮助所罗门逐步恢复市场信誉和业务正常运转。他的务实态度和专业能力得到了巴菲特的认可，在巴菲特主导的重组和改革中承担了关键执行角色。

所罗门兄弟危机最终以与美国财政部的和解告终，公司得以继续运营。巴菲特在此事件中展现了危机处理的能力，也借此机会在公司内部推行了一系列治理改革。莫恩作为管理层代表，在配合巴菲特完成整改和重建方面发挥了积极作用。此后所罗门逐步回归正轨，最终成为伯克希尔的全资子公司。

## 关键年份事件

- **1991年**：所罗门兄弟国债丑闻爆发，莫恩在公司危机中承担管理职责
- **1992年**：协助巴菲特完成所罗门内部整改与监管和解
- **1993年后**：参与所罗门并入伯克希尔的整合工作
