# 唐·库赫（Don Keough）

- **角色职位**：可口可乐公司前总裁（President）
- **与巴菲特关系**：可口可乐核心高管，与巴菲特私交深厚，是巴菲特的老朋友

## 主要事迹

唐·库赫是可口可乐公司历史上最具传奇色彩的高管之一。他在可口可乐任职长达数十年，从基层做起，一路晋升至公司总裁兼首席运营官，与CEO罗伯托·戈伊苏埃塔（Roberto Goizueta）形成了黄金搭档。库赫不仅是一位杰出的商业领袖，更以直言不讳、幽默风趣的个性著称，是可口可乐公司文化的灵魂人物之一。他深谙企业运营，对可口可乐的全球扩张战略有着不可替代的贡献。在戈伊苏埃塔任内推动可口可乐全球化的进程中，库赫作为运营操盘手，承担了大量关键工作。巴菲特与库赫的友谊是商业史上最经典的"伯乐与良驹"故事之一——巴菲特曾表示，库赫是他最欣赏的人之一。

## 关键年份事件

- **1981年**：戈伊苏埃塔出任可口可乐CEO，库赫作为核心副手共同推进改革
- **1985年**：可口可乐推出"新可乐"（New Coke），库赫在危机中发挥关键作用，最终推动公司回归经典配方
- **1993年**：库赫随戈伊苏埃塔一同受到巴菲特增持可口可乐的关注
- **1997年**：戈伊苏埃塔去世后，库赫继续以高级顾问身份为可口可乐服务
