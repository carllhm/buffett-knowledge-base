# 弗兰克·奥尔森

- **角色职位**：赫兹公司（Hertz）CEO
- **与巴菲特关系**：伯克希尔·哈撒韦曾投资或涉及赫兹公司相关交易

## 主要事迹

弗兰克·奥尔森曾担任赫兹公司（Hertz Global Holdings）CEO。赫兹是全球最大的汽车租赁公司之一，在美国及全球数十个国家拥有数千个服务网点，为商务旅客和休闲游客提供租车服务。奥尔森作为 CEO，负责赫兹在全球范围内的运营战略、车队管理和客户服务体系的整体运作。

赫兹的商业模式核心在于大规模车队管理——通过采购和运营数以万计的车辆，以租车费收入覆盖车辆折旧和资金成本。奥尔森在这一业务模式下积累了丰富的经验，深谙车队规模、车辆残值管理和市场需求之间的动态平衡。这种需要精细化运营和强大的现金流管理能力的业务，与巴菲特偏好的"资本密集但能产生稳定回报"的商业模式存在一定共鸣。

巴菲特对赫兹等租车公司的关注由来已久。赫兹曾在不同时期进入伯克希尔的投资视野，奥尔森作为掌舵人在公司的战略方向和财务表现方面发挥着关键作用。租车行业具有明显的周期性特征，与航空业类似受到商务旅行和旅游市场的直接影响。奥尔森的领导经验帮助赫兹在行业波动中保持运营稳定，也使得赫兹成为伯克希尔在交通服务领域持续关注的标的之一。

## 关键年份事件

- **CEO 任期**：担任赫兹公司 CEO，主导全球汽车租赁业务的运营管理
- **行业调整期**：面对旅游市场波动和车辆残值风险等挑战，推动赫兹运营优化
- **后续发展**：赫兹经历了重组和变革，奥尔森任期内为公司在行业周期中的稳定发展奠定基础
