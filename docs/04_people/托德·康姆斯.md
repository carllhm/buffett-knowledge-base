# 托德·康姆斯（Todd W. Combs）

## 基本信息

| 属性 | 内容 |
|------|------|
| 全名 | Todd W. Combs |
| 出生 | 约1969年 |
| 公司 | [[伯克希尔哈撒韦]] |
| 职位 | 投资经理 |
| 任期 | 2009年至今 |

## 职业生涯

### 早年经历
- 早年经历低调，专注于投资研究
- 在加入伯克希尔前积累了丰富的投资经验

### 对冲基金经历
- 2009年之前运营对冲基金 **Par Capital Management**
- 在对冲基金期间建立了独特的投资方法论
- 以深入的基本面研究著称

## 加入伯克希尔

### 招聘过程
- 2009年加入[[伯克希尔哈撒韦]]（先于韦斯勒）
- 先由猎头主动联系
- 随后与[[沃伦·巴菲特]]进行面试
- 整个招聘过程由[[阿吉特·贾恩]]主导

### 初始角色
- 接手管理约**10亿美元**的股票组合
- 初期独立管理个人账户投资

## 投资风格

### 核心特点
1. **与巴菲特互补**：关注巴菲特较少涉足的领域
2. **偏好小型股**：善于挖掘中小市值投资机会
3. **深入研究**：重仓前必做详尽的基本面分析
4. **长期持有**：一旦认定优秀公司，长期持有不频繁交易

### 研究深度
- 对投资标的进行深度尽职调查
- 关注公司竞争优势的可持续性
- 重视管理层质量和诚信

## 代表投资

### 知名持仓
- 在[[伯克希尔哈撒韦]]任职期间有多个显著的投资决策
- 投资风格与[[卢·辛普森]]有相似之处
- 同样注重企业的内在价值和长期潜力

## 角色演变

### 2010年：接管GEICO
- 开始管理[[GEICO]]的股票组合
- 接管约**30亿美元**的GEICO投资组合
- 接替[[卢·辛普森]]的部分职责

### 2011年后：扩大管理范围
- 逐渐扩大管理范围
- 从单一选股到负责整个保险投资组合
- 承担更多战略性投资职责

## 与其他投资经理的关系

- 与[[斯坦·利普西]]同为伯克希尔重要投资人才
- 与[[卢·辛普森]]在GEICO有传承关系
- 与[[阿吉特·贾恩]]保持密切工作关系

## 巴菲特评价

巴菲特对康姆斯的评价：
- 认可其独立的投资判断能力
- 赞赏其深入研究的工作方法
- 认为其为伯克希尔带来了新的投资视角
