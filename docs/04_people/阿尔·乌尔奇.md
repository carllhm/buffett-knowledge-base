# 阿尔·乌尔奇（Al Urich）

- **角色职位**：飞安国际（FlightSafety）CEO
- **与巴菲特关系**：飞安国际被伯克希尔收购后，乌尔奇担任CEO，负责伯克希尔旗下飞行培训业务

## 主要事迹

阿尔·乌尔奇是飞安国际（FlightSafety International）的核心领导者。飞安国际是全球最负盛名的民用及商务航空飞行培训机构之一，为飞行员提供高仿真模拟器培训和认证服务。公司创立于1951年，总部位于纽约，是全球飞行员培训行业的标杆企业。飞安国际以严苛的训练标准和卓越的教学质量著称，为全球各大航空公司和私人飞机运营商培养了无数优秀飞行员。1996年，伯克希尔·哈撒韦收购飞安国际，将其纳入伯克希尔的航空业务板块。乌尔奇在飞安国际担任CEO期间，将公司的培训业务进一步专业化、规模化，确保伯克希尔在航空安全领域的领先地位。飞安国际的高质量培训服务与伯克希尔一贯追求卓越的理念完美契合，是伯克希尔多元化业务组合中不可或缺的组成部分。

## 关键年份事件

- **1951年**：飞安国际创立，成为美国领先的飞行培训机构
- **1996年**：伯克希尔·哈撒韦收购飞安国际，阿尔·乌尔奇继续担任CEO
- **1996年后**：在乌尔奇领导下，飞安国际持续扩展训练中心网络，保持行业领先地位
