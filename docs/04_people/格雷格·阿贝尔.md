# 格雷格·阿贝尔（Gregory W. Abel）

## 基本信息

| 项目 | 内容 |

| **全名** | Gregory Warren Abel |
| **出生日期** | 1961年 |
| **出生地** | 加拿大埃德蒙顿 |
| **公司** | [[伯克希尔哈撒韦]]、[[中美能源]]（BHE） |
| **职位** | 伯克希尔副董事长（非保险业务）；2025年起任 CEO |
| **任期** | 2021年1月起任副董事长；2025年5月起接任 CEO |

## 职业生涯

### 早年经历

阿贝尔在加拿大成长，毕业于阿尔伯塔大学（University of Alberta），获得会计学位，后取得注册会计师（CA）资格。早年曾在普华永道（PricewaterhouseCoopers）从事审计工作，积累了扎实的财务基础。

### 加入中美能源

1992年，阿贝尔加入中美能源控股公司（MidAmerican Energy Holdings，后更名为 Berkshire Hathaway Energy，简称 BHE），从财务高管起步。他以出色的运营能力和资本配置眼光，逐步晋升为公司 CEO，带领 BHE 从一家区域电力公司发展为横跨能源、公用事业、管道、可再生能源的综合性能源巨头。

### 伯克希尔的崛起

[[伯克希尔哈撒韦]]于1999年首次入股中美能源，[[沃伦·巴菲特]]与[[查理·芒格]]对阿贝尔的管理能力印象深刻。此后 BHE 在其领导下持续扩张：

- 收购 PacifiCorp（美国西部大型电力公司）
- 大举投资风能、太阳能等可再生能源
- 收购 NV Energy（内华达州公用事业）
- 管理超过百亿美元的资本支出项目

2018年，阿贝尔晋升为伯克希尔副董事长，负责监管所有**非保险业务**子公司，包括 BNSF 铁路、BHE、伯克希尔旗下工业与零售板块等数十家子公司。

## 核心角色

### 为何被视为接班人

2021年5月，[[查理·芒格]]在股东大会上无意中透露"Greg（阿贝尔）将接替沃伦"，随后巴菲特正式确认：格雷格·阿贝尔是伯克希尔的既定接班人。

巴菲特选择阿贝尔的核心理由：

1. **运营能力卓越**：在极度复杂的能源与基础设施领域，长期保持高效运营与合理资本回报
2. **文化契合**：深刻理解并践行伯克希尔"买入并持有、充分授权管理层"的文化
3. **资本配置能力**：能够识别大型项目中的风险与回报，具备与巴菲特相似的长期视角
4. **低调务实**：不谋求媒体曝光，专注执行，与伯克希尔风格高度一致

### 主管业务范围

作为非保险业务副董事长，阿贝尔监管的核心版块包括：

| 板块 | 代表企业 |
|-----|---------|
| **能源与公用事业** | Berkshire Hathaway Energy（BHE） |
| **铁路运输** | BNSF Railway |
| **制造业** | IMC、Precision Castparts、ISCAR 等 |
| **零售与服务** | See's Candies、Nebraska Furniture Mart、Dairy Queen 等 |
| **建筑与房地产** | Clayton Homes、Johns Manville 等 |

## 投资风格与特点

- **资本密集型项目的驾驭者**：在监管严格、资本支出巨大的能源行业游刃有余，擅长长周期回报评估
- **可再生能源先行者**：在巴菲特的支持下，BHE 成为全美最大的可再生能源投资者之一，深刻理解能源转型趋势
- **运营而非投机**：风格偏向深度运营管理，而非纯粹的金融套利，与芒格所倡导的"优秀企业合理价格"路线契合
- **稳健低调**：极少公开接受采访，聚焦企业本身，不炒作个人形象

## 与巴菲特的关系

巴菲特与阿贝尔合作逾二十年，关系亦师亦友。巴菲特多次在股东信和公开场合盛赞其管理才能：

> "Greg Abel 在能源领域表现出的判断力令我印象深刻。他理解如何以合理的资本回报运营复杂的受监管业务。"

2021年芒格"失口"确认接班事宜后，巴菲特随即补充，阿贝尔完全理解并认同伯克希尔的文化——这是巴菲特认为比财务才能更为关键的特质。

2025年5月，在伯克希尔年度股东大会上，巴菲特正式宣布退休，格雷格·阿贝尔正式接任伯克希尔哈撒韦 CEO，成为这家市值逾万亿美元企业的新掌舵人。
