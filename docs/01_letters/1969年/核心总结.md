# 1969年 核心总结

## 年度业绩

1969年，道琼斯指数上涨15.7%，而巴菲特合伙企业取得35.9%的收益率。年末企业净资产已达到约1.35亿美元。从1957年至1969年的12年间，合伙企业累计取得2610.6%的回报，年化复合收益率高达31.6%，远超同期道指表现。这一年不仅是合伙企业时代的收官之年，更是一个投资传奇的巅峰注脚。

## 重要事件

1969年5月29日，巴菲特正式向所有合伙人发出信件，宣布将逐步清算合伙企业并退还资金。这封著名的"分手信"标志着巴菲特投资生涯一个时代的终结。他在信中坦诚说明：市场环境已发生根本性变化，适合自己风格的低估值机会日益稀少，勉强操作只会损害合伙人利益。清盘提供了三个选项：将资金投入格雷厄姆推荐的股票组合、赎回现金，或转换为伯克希尔·哈撒韦股票。绝大多数合伙人选择了后者。

## 投资理念

巴菲特在告别信中再次重申：长期跑赢指数是可实现的目标，但需要坚持独立思考、不随波逐流。他警告合伙人对任何承诺高回报的"超级明星经理"保持警惕，明确表示自己不会再做代客理财。这一决定体现了巴菲特对能力圈的清醒认知——当市场不再提供符合其标准的机会时，退场比勉强继续更为诚实。

## 关键人物

本杰明·格雷厄姆作为巴菲特的导师，其推荐的股票组合成为清盘后部分合伙人的资金去向。沃尔特·施洛斯作为格雷厄姆门徒中的另一位代表人物，也被巴菲特推荐为潜在的资金管理人。而巴菲特本人，则在此后数十年间，以伯克希尔·哈撒韦为载体，开启了另一段更为波澜壮阔的投资生涯。
