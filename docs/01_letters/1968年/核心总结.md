# 1968年 核心总结

## 年度业绩

1968年，巴菲特合伙企业取得58.8%的收益率，创下历史最高纪录，大幅跑赢道琼斯指数的7.7%涨幅。这一年成为合伙企业时代最辉煌的年份之一，企业净资产突破1亿美元大关，达到约1.04亿美元。12年间，合伙企业累计回报率已达相当可观的水平，为后续清盘奠定了坚实的财务基础。

## 重要事件

联合棉花商店在比尔的精心运营下表现稳健，更值得注意的是，本·罗斯纳（Ben Ros纳特）正式接管了该业务的日常管理。本·罗斯纳的加入为联合棉花商店带来了新的活力，也为日后伯克希尔纺织业务的转型埋下伏笔。与此同时，国家赔偿保险公司在杰克·林格沃尔特（Jack Ringwalt）的领导下继续展现卓越的承保与投资能力，成为巴菲特保险帝国的又一基石。

## 投资理念

巴菲特在这一年继续践行其"烟蒂股"哲学与套利机会并行的策略。他对低估类证券的深度挖掘以及对事件驱动型机会的敏锐把握，使合伙企业在各种市场环境下均能获取超额收益。同时，他对管理层品质的重视也愈发明显——本·罗斯纳接管联合棉花商店即是这一理念的体现。

## 关键人物

本·罗斯纳作为联合棉花商店的新管理者，展现出卓越的商业才能。杰克·林格沃尔特则是国家赔偿保险的灵魂人物，其在保险业务上的精湛技艺持续为合伙企业贡献稳定的浮存金来源和投资利润。
